# BAS SMART REPORTING — Perubahan v0.3

## Penyempurnaan yang ditambahkan
- Pencarian laporan berdasarkan judul, keterangan, kategori, subfolder, dan departemen.
- Filter teks bagian/departemen pada daftar dan hasil ekspor.
- Edit laporan tersimpan.
- Hapus laporan dengan dialog konfirmasi.
- Ekspor PDF multi-halaman agar seluruh hasil filter dapat dimasukkan, bukan hanya 43 baris pertama.

## Catatan
- Penghapusan laporan tidak menghapus file foto/video yang sudah tersimpan. File media sengaja dipertahankan agar tidak menghapus dokumentasi yang mungkin dipakai laporan lain atau diperlukan untuk arsip.
- Ekspor JPG masih berupa ringkasan satu halaman dengan batas jumlah baris; gunakan PDF atau XLSX untuk arsip data lengkap.
- Source belum dikompilasi atau diuji di perangkat Android. Jangan gunakan sebagai aplikasi produksi sebelum build dan pengujian fisik selesai.
